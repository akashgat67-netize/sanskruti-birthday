# Sanskruti's Birthday Surprise 💗

A responsive romantic birthday website made by Akash for Sanskruti, for 9 November.

## Open in VS Code
1. Extract `sanskruti_birthday_website.zip`.
2. Open the extracted `sanskruti_birthday_website` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code **Live Server** extension and click **Go Live**.
4. Keep the `images` folder next to `index.html`; the gallery uses those local photos.

## Included
- Romantic pink responsive design
- Four supplied couple photos in the hero and memory gallery
- Interactive balloon love notes
- Birthday wish animation
- Bouquet and floating hearts
- Personal English love letter
- Final hug surprise
- Gentle animated music made in-browser (no external audio file)

The site uses Google Fonts if internet is available, with local serif/sans-serif fallbacks. No framework or build step is required.
